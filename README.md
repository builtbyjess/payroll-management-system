# Payroll Management System

A terminal-based payroll management application built in Python to streamline employee wage calculations, overtime tracking, and monthly payroll summaries.

## Features
- **Employee Records:** View preloaded employee details and pay rates from a structured command-line menu.
- **Total Monthly Payroll:** Calculate organization-wide monthly payroll totals excluding overtime.
- **Individual Salary Breakdown:** Compute weekly and monthly earnings for individual employees, including automated `1.5x` overtime pay calculations.
- **Interactive CLI Menu:** Navigate tasks easily through a clean, menu-driven terminal interface.

## Tech Stack
- **Language:** Python 3
- **Interface:** Command-Line Interface (CLI)

## How to Run
1. Make sure you have **Python 3** installed on your computer.
2. Download `Payroll_Management_System.py` from this repository.
3. Open it in your IDE (like PyCharm or VS Code) or terminal and run `python Payroll_Management_System.py`.
